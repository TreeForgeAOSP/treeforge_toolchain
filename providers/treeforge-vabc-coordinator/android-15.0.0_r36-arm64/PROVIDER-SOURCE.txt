AOSP is used only as the developer build workspace for producing this
bundled provider. TreeForge runtime use of this provider does not require
an AOSP checkout.

The coordinator embeds the full COW-capable libsnapshot implementation.
TreeForge keeps normal Recovery semantics while narrowly allowing
Virtual A/B creation from TreeForge Recovery through
AllowVirtualAbInRecovery().

The current provider is intentionally probe-only. Snapshot creation,
COW writes, and slot activation remain disabled until their separate
Recovery safety milestones are accepted.

The coordinator reuses byte-identical Android r36 runtime files already
bundled by the aosp-adbd-recovery runtime provider. Its provider bundle owns
only the coordinator executable and the additional libchrome, libcutils,
and libevent runtime libraries.
